## Overview

Auto Deconstruct monitors all mining drills in a Factorio map and automatically marks any drill sitting over a fully depleted ore patch with a deconstruction planner order, so construction bots immediately clean up the exhausted miners without manual intervention. An optional pause-before-mark delay prevents false positives from slow-growing patches.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Auto Deconstruct** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Auto Mark Depleted** | Exhausted mining drills are marked for deconstruction automatically |
| **Bot Integration** | Marked drills are immediately queued for roboport construction bots |
| **Depletion Delay** | Configurable tick delay before marking prevents false positive depletion |
| **All Drill Types** | Works with electric, burner, and any modded mining drill entities |
